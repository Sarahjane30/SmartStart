## When to raise an access request
Any software or system outside the standard kit, such as Confluence spaces, GitHub organisations or design tools, needs an access request in ServiceNow. Raise it as soon as the work is known so access is ready before the joiner needs it.

## Who approves
The hiring manager requests and justifies the access, and the IT Service Desk approves and grants it. HR does not approve system access. SmartStart and NIA can recommend access but never grant it.

## What a request must include
Each request names the system, the access level (Viewer, Editor or Admin) and a short business justification. Admin access needs a written reason and is reviewed by IT Identity.

## Least privilege
Grant the lowest access level that lets the joiner do their work. Interns receive Viewer or Editor access only; Admin access is not granted during onboarding.

## Turnaround
IT aims to decide on a complete access request within 1 working day. Incomplete requests are returned to the requester with the missing detail.
