## The five stages
Every joiner moves through the same stages in order: Offer Accepted, Documents Pending, IT Provisioned, Day-1 Oriented and Project Ready. A stage only clears when its owner finishes the work in the system of record, and SmartStart detects the change from that system.

## Who owns each stage
HR (People Ops) owns offer acceptance and the document packet in iCIMS. The IT Service Desk owns laptop, VPN and access provisioning in ServiceNow. The hiring manager owns Day-1 orientation, the mentor introduction and the first project in Jira. Onboarding Operations watches the whole pipeline and steps in when a handoff stalls.

## Handoff from HR to IT
IT provisioning starts only after the document packet is Complete in iCIMS. HR sends the standard IT request when the onboarding plan is approved, so IT is never asked to provision for someone whose documents are still open.

## Handoff from IT to the manager
When the ServiceNow request is fulfilled and the laptop is Delivered, SmartStart notifies the hiring manager that preparation can begin. The manager then confirms the mentor and books Day-1 orientation.

## Project ready
A joiner is project ready when documents are complete, IT setup is delivered, required learning is done and Jira project access is granted. Managers assign the first project in Jira only after Day-1 orientation.
