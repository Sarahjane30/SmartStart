# Publishing the Waters Confluence page

Source document: [`confluence-what-is-waters-phase1.md`](./confluence-what-is-waters-phase1.md)

## Confluence Cloud (recommended)

1. Create a page titled **What is Waters? — Prototype Overview & Phase 1**.
2. In the editor, use **/** → Markdown (or paste into a Markdown macro), and paste the full source document.
3. Optional macros after paste:
   - Wrap §1 Motive opening in an **Info** panel.
   - Wrap §6.2 Deferred in a **Note** panel.
   - Wrap §5.4 Safety controls in a **Warning** or **Tip** panel.
4. Add labels: `smartstart`, `waters`, `phase-1`, `onboarding`, `prototype`.
5. Restrict edit to the owning squad; allow view for onboarding / L&D / engineering.

## What this page is / is not

| Is | Is not |
| --- | --- |
