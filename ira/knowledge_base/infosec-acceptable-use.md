## Company devices
Your Waters laptop is for business use; limited personal use is allowed if it doesn't affect your work or security. Keep it locked when unattended and never let others use it.

## Installing software
Only install software from the Company Portal / Software Center. Anything else needs a ServiceNow software request so Information Security can review it. Local admin rights are not granted by default.

## USB and removable media
USB storage is blocked by default. If you need an exception, raise a ServiceNow request with your manager's approval.

## Personal devices
Access email and Teams on a personal phone only through the approved Microsoft apps with device enrolment. Do not store Waters files on personal computers.

## AI tools and ChatGPT
Use only approved AI tools listed on the intranet, such as the Waters enterprise Copilot. Public tools like ChatGPT may be used only for non-confidential tasks. Never paste confidential, customer or personal data into public AI chatbots.

## Monitoring
Company systems are monitored for security purposes in line with local law. Do not expect privacy for data stored on Waters systems.
